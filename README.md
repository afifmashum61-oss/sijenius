# 🦜 Si Jenius: Media Pembelajaran Interaktif Daulah Abbasiyah

Aplikasi web edukasi interaktif Sejarah Kebudayaan Islam (SKI) Kelas VIII Madrasah Tsanawiyah (MTs) berbasis **Kurikulum Berbasis Cinta (KBC)**.

Mengangkat tema kejayaan peradaban emas Islam (*The Islamic Golden Age*) di kota Baghdad pada masa Daulah Abbasiyah bersama maskot burung cerdas **Si Jenius**.

---

## 🌟 Fitur Utama

### 🗺️ Peta Petualangan 4 Misi:
1. **Misi 1: Sosiodrama Majelis Ilmu** — Mempelajari dinamika majelis ilmu istana bersama para khalifah dan ulama.
2. **Misi 2: Kuis Peradaban** — Uji pemahaman materi kemajuan intelektual, sains, dan kebudayaan Islam.
3. **Misi 3: Susun Urutan Peristiwa** — Mengurutkan tonggak sejarah penting berdirinya Baghdad hingga runtuhnya peradaban.
4. **Misi 4: Cermin Hati & Sertifikat** — Refleksi nilai cinta ilmu dan penerbitan sertifikat digital otomatis dengan nama siswa.

### 📚 Menu Tambahan & Perangkat Pembelajaran:
1. 🎬 **Video Pembelajaran**: Teater video edukasi sejarah peradaban Baghdad dan Baitul Hikmah (mendukung file MP4 kustom).
2. 🖼️ **Slide Materi**: Modul tayangan presentasi materi pembelajaran interaktif.
3. 📖 **Komik Digital**: Serial komik petualangan 4 bab mengarungi kejayaan kota Baghdad bersama Si Jenius.
4. 🎮 **Game Petualangan**: Game interaktif mandiri (*Si Jenius: Petualangan Dimulai*) dengan kontrol Layar Penuh dan Mulai Ulang.
5. 📝 **LKPD (Lembar Kerja Peserta Didik)**: Lembar kerja diskusi kelompok (C4, C5, C6) dan refleksi Panca Cinta dengan auto-save & siap cetak.
6. 📋 **RPP KBC (Ruang Guru)**: Rencana Pelaksanaan Pembelajaran Kurikulum Berbasis Cinta terstruktur lengkap.

---

## 🚀 Cara Menjalankan Secara Lokal

1. Pastikan telah terinstal [Node.js](https://nodejs.org/).
2. Buka terminal di direktori proyek ini:
   ```bash
   node server.js
   ```
3. Buka browser pada alamat:
   ```
   http://localhost:3000
   ```

---

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3**: Antarmuka responsif bernuansa perkamen klasik Daulah Abbasiyah (*Islamic Golden Age palette*).
- **JavaScript (Vanilla)**: State management lokal (`localStorage`), canvas game rendering, audio player, dan sertifikat generator.
- **Node.js**: HTTP static server lokal dengan HTTP Range streaming support.
